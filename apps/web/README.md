# Web App

The current React app lives in `frontend/`.

This folder exists as the future-facing app boundary for a monorepo layout:

```text
apps/
  api/
  worker/
  web/
```

For now, run the web app from the existing folder:

```powershell
cd frontend
npm.cmd run dev
```

Open:

```text
http://127.0.0.1:5173
```
